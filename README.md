# Advance Painting & Epoxy Flooring Experts

Static website, ready for GitHub Pages. No build step.

## Publish on GitHub Pages
1. Create a repository and upload every file in this folder to the root (including `.nojekyll`).
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Your site appears at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
4. Replace `https://YOUR-USERNAME.github.io/YOUR-REPO/` in `sitemap.xml` and `robots.txt` with your real address (or custom domain).
